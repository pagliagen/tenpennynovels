Prestavolto — Test Ricerca VIP

Cerca un VIP anche con il nome sbagliato. Usa Wikipedia (fuzzy search) per trovare il nome corretto, poi Wikidata per verificare che sia una persona reale e ottenere le info tipizzate. Nessuna API key, nessuna AI, tutto gratis.

Come funziona (pipeline):

  1. Wikipedia Search — fuzzy matching, corregge errori di battitura → titoli corretti
  2. Wikipedia PageProps — da ogni titolo ottiene il wikibase_item (Wikidata QID)
  3. Wikidata GetEntities — con i QID ottiene: tipo (P31), occupazione (P106), foto (P18), nascita (P569)
  4. Filtro — tiene solo quelli con P31 = Q5 (essere umano)
